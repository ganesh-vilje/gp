# common_passwords.txt — vendored weak-password list for core.validation.validate_password.
#
# security-architecture.md §3 names Django's BSD-3-licensed ~10k-entry
# `common-passwords.txt.gz` as the reference list (dependency-strategy.md §5,
# "Vendored data assets"). This sandbox has no network access to fetch and
# attribute that exact licensed file (source URL, version, licence text), so
# this is a smaller (298-entry), independently curated list of widely known
# weak passwords/keyboard patterns, used per the T-005 review's own fallback
# guidance ("if unspecified, >=200 widely known weak passwords, no network
# fetch needed"). Swapping in the real Django file (with its licence
# attribution recorded here and in the licence inventory) is follow-up work,
# not blocked by anything in this module's code.
#
